## ✨ Aprendizaje

¿Que concepto nuevo aprendi gracias a la IA?
En html
 Usar: section y Clases de Bootstrap:
      - 'container': Centra el contenido y le da márgenes a los lados.(repaso)
      - 'py-5': Añade relleno (padding) vertical arriba y abajo para que no quede amontonado.
      - 'text-center': Centra todo el texto y elementos que estén dentro.(repaso)
      - 'display-4': Clase de Bootstrap que aumenta el tamaño de la fuente para títulos principales.
      - 'mb-3': Añade un margen abajo (margin-bottom) para separarlo del párrafo.
      - 'lead': Hace que el texto sea un poco más grande y estilizado, ideal para introducciones.
    Contenedor 'row' (Fila): Activa el sistema de rejilla de Bootstrap para que podamos poner tarjetas alineadas.

En css: .nav-link:hover para cuando pasas el cursor cambia de color.
        .btn-primary:hover justo como en el texto de nav pero en cambio de los botones

En JavaScript, la palabra clave let se utiliza para declarar variables. Una variable es un contenedor o como ejemplo una caja con el nombre donde puedes almacenar datos que pueden cambiar durante la ejecución de tu el programa.
